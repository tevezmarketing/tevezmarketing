## 3️⃣ INGENIERÍA DE CONVERSIÓN & CIERRE

### Optimización de Tasa de Conversión (CRO)
1. **Auditoría Baseline:** Visitas, conversiones, cuellos, CPA, LTV
2. **Identificar Cuellos:** Heatmaps, recordings, analytics
3. **Hipótesis de Mejora:** Basadas en datos y psicología
4. **A/B Testing:** Una variable a la vez, mínimo 100 conversiones
5. **Documentar & Escalar:** Qué funcionó, por qué, guardar aprendizaje

### Elementos que Mejoran CRO
- **Copywriting:** Headlines específicos, subheaders, bullets de beneficio, social proof, risk reversal
- **Formularios:** Máximo 5 campos, progresivos, inline validation, conditional fields
- **CTAs:** Color contrastante, microcopy claro, posición múltiple, mobile-first
- **Ofertas:** Específicas, limitadas en tiempo/cantidad, fáciles de entender
- **Urgencia:** Real (no artificial), contador regresivo, cupos restantes, demanda mostrada
- **Confianza:** Años negocio, número clientes, certificaciones, garantía dinero de vuelta

### Atribución Multi-Touch
- Registrar cada interacción (entry point → conversión)
- Asignar % a cada canal según participación real
- Ejemplo real: 20% Meta + 20% Google + 30% Email + 30% Contenido = $10k venta

### TM Traking (CAPI)
- Problema: iOS 14+ bloqueó pixels, Meta pierde 30-40% conversiones
- Solución: Enviar conversiones desde servidor a Meta (server-to-server)
- Resultado: Recuperar conversiones perdidas, algoritmo optimiza mejor

### Protocolo de Cierre (5 Pasos)
1. **Descubrimiento (30m):** Relación, necesidad, autoridad, urgencia
2. **Propuesta (1-2d):** Personalizada, desglose costo, ROI, referencias
3. **Presentación (30-45m):** Diálogo, esperar objeciones, aclarar, próximo paso
4. **Objeciones:** "Es caro" → "¿Cuánto cuesta no hacer nada?", "Pensarlo" → "Cita viernes"
5. **Cierre:** Acuerdo explícito, próxima reunión agendada, confirmación email

### Señales de Intención
- 🟢 **Verdes:** "¿Cuándo empezamos?", pregunta términos pago, compara, menciona budget
- 🟡 **Amarillas:** Pregunta features, quiere referencias, "Suena bien" (sin agenda)
- 🔴 **Rojos:** "Llamamos en 6 meses", pregunta precios (no problemas), "Viendo opciones"

### Automatización de Cierre
```
Lead llega → Calificado automático → Score > 15: Alerta
Email bienvenida automático → Propuesta automática
Si abre: Alerta real-time → Follow-up 24h, 48h, 72h
Sin respuesta 7d: Nutrición automática
```
**Impacto:** 70% follow-up sin tocar teléfono

## 4️⃣ IA Y AUTOMATIZACIÓN INTELIGENTE

### Filosofía
> *IA no reemplaza estrategia. La multiplica. Y funciona mientras duermes.*

Cada agente opera en **producción real**, manejando clientes, tomando decisiones que impactan dinero.

### Agente 1: Tevia Chat (Conversacional)
**Propósito:** Atender, calificar y dirigir prospectos 24/7 sin intervención humana

**Arquitectura:**
```
Prospecto inicia chat
    ↓
Captura contexto (hora, fuente, ubicación, historial)
    ↓
Conversación SPIN (Situación → Problema → Implicación → Necesidad)
    ↓
Scoring real-time (cada respuesta suma puntos, máx 20)
    ↓
Detección emocional (Frustración/Curiosidad/Decisión/Aprendizaje)
    ↓
Si score >= 15: Alerta equipo comercial
Si emoción = Decidido: Flujo de cierre automático
    ↓
Captura contacto, consentimiento → Pasar a TM Quotes
```

**Scoring:** Inicia chat (+1), problema específico (+3), pregunta precio (+3), solicita consultoría (+5), proporciona contacto (+4), abre propuesta (+2), requiere llamada (+2)

**Detección Emocional:**
- **Frustración:** "No funciona", "cansado", "harto" → Validar primero, luego solución
- **Curiosidad:** "Cómo funciona", "cuéntame" → Educar, contar historias
- **Decisión:** "Cuándo empezamos", "disponibilidad" → Acelerar cierre
- **Aprendizaje:** "Quiero aprender", "enseña" → Recursos, guías

**Espejo de Lenguaje:** Prospecto técnico → Respuesta técnica. Prospecto simple → Sin jerga.

**Resultados:** Tiempo respuesta -99.7% (5.2h → 47s), tasa respuesta +194% (34% → 100%), tasa cierre +133% (12% → 28%)

### Agente 2: Scoring Dinámico

**Output:** Score 0-100
- 80-100: Cierre probable → Llamada inmediata
- 60-79: Interesado → Email + WhatsApp
- 40-59: Posible → Nutrición contenido
- 20-39: Débil → Descargas, webinars
- 0-19: No cierra → Archivar

**Mejora:** Retroalimentación mensual, ajuste modelo, precisión aumenta con tiempo

### 📈 **PATRONES DE ÉXITO (Todos Casos)**

1. **Problema: Conversión, No Tráfico**
   - 9/12 clientes tienen tráfico suficiente
   - Problema: No lo convierten
   - Solución Dynamics: 2x conversión del mismo tráfico

2. **Dinero está en Cierre**
   - Promedio: 7% leads → clientes (sin sistema)
   - Con Tevia: 18-35% conversión
   - Multiplicador: 2.5-5x ingresos

3. **Tiempo = Dinero**
   - Automatización follow-up ahorra 20-30h/mes
   - Dueño/equipo en tareas repetitivas
   - Máquina hace eso, humano cierra

4. **Ubicación Importa**
   - Ibagué ≠ Lérida ≠ Honda
   - Messaging genérico no funciona
   - Dynamics personalizado: +50% conversión

5. **ROI Mejora Rápido**
   - Semana 1-2: Sistema operando
   - Semana 3-4: Primeros patrones
   - Semana 5-8: ROI positivo
   - Mes 3+: Compounding
